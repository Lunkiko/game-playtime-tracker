# Game Playtime Tracker

背景常駐的 Windows 小工具,自動記錄你玩遊戲的時數。沒有資料庫,紀錄存成CSV文字檔,放在你自己的電腦上。

目前會自動偵測:
- `games.json` 裡列出的遊戲(預設是英雄聯盟LOL / 特戰英豪VALORANT,可在設定裡改)
- 任何在跑的 Steam 遊戲(免設定,自動抓)

## 安裝 / 第一次啟動

1. 下載這個專案(Code → Download ZIP,解壓縮到你喜歡的資料夾)
2. 雙擊 **`啟動.vbs`**
   - 不會跳出任何視窗,工具會安靜地在背景啟動
   - 右下角系統匣(時鐘旁邊)會出現一個小圖示,數字代表今天已經玩的時數
3. 右鍵點這個圖示,選單裡可以:
   - **每日遊戲時數**:看歷史紀錄(本月/本週總計、每天明細)
   - **設定**:
     - 開機時自動啟動(勾選後,下次開機會自動跑起來,不用再手動雙擊)
     - 偵測Steam遊戲開關
     - 輪詢間隔、最短紀錄秒數
     - 系統匣圖示顏色
     - 遊戲清單管理(新增/編輯/移除要追蹤的遊戲,新增時可以直接從「目前執行中的程式」列表點選,不用自己打英文process名稱)

## 需求

純 Windows 內建的 PowerShell(Windows 10/11都有,不用額外安裝任何東西)。

## 資料存在哪

- `logs/yyyy-MM.csv`:實際的遊戲時數紀錄,一個月一個檔案
- `games.json`:你設定的遊戲清單
- `settings.json`:你調整過的設定(沒改過設定前不會有這個檔案)

這三個檔案都在你自己電腦上,不會上傳到任何地方。

## 關閉工具

工作管理員裡找到 `powershell.exe`(背景執行track.ps1的那個),結束工作即可。若有勾選開機自動啟動,之後想徹底關閉請到「設定」取消勾選,或手動刪除:
`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\GamePlaytimeTracker.vbs`
